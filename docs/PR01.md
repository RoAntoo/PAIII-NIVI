# NIVI — PR 01: base Android, contrato de tareas y ajustes

## Objetivo

Preparar NIVI para Android conservando Angular/Ionic, el backend y la autenticación actuales, con ajustes persistentes y CRUD de tareas completo.

## Cambios

- Capacitor 8.6.0 y proyecto Android (`ar.edu.nivi.app`, nombre NIVI).
- Configuración de API para emulador/celular, scripts de build/sync y guía `docs/android-setup.md`.
- Ajustes persistentes con Preferences 8.0.1; seis módulos identificados como pendientes de implementación. Lugares y offline desactivados por defecto.
- Validación y mapeo de tareas centralizados; defaults MANUAL/GENERAL para tareas antiguas.
- Categoría, origen y UUID opcional de cliente persistidos mediante migración H2 compatible, con rollback documentado y probado.
- Edición de estado, fecha de completado/reapertura y borrado individual confirmado; protección de proyectos cerrados y pertenencia al proyecto.
- Nombre/tokens NIVI y estilos/iconos locales para Android.

## Contrato

Se conservan las rutas `/projects/{projectId}/tasks` y los IDs numéricos. `PUT` agrega `status/category`; se incorpora `DELETE /projects/{projectId}/tasks/{taskId}`. Se conservan horas, responsable y fechas existentes. `clientRequestId` es opcional y único; un duplicado devuelve 409, sin implementar todavía sincronización ni replay idempotente.

Respaldar la base antes de actualizar. Diagnóstico, contrato y migración: `docs/pr01-base.md`.

## Verificación

- `npm --prefix frontend test -- --watch=false`: 41 pruebas aprobadas.
- Backend con JDK 21: `mvnw.cmd verify "-Dnivi.build.directory=target-audit"`: 56 pruebas aprobadas.
- `npm --prefix frontend run build`: aprobado.
- Capacitor Android generado y sincronizado; Preferences nativo registrado.

## Pendientes y riesgos

- **Falta compilar/instalar el APK y validar en celular:** este entorno no tiene Android SDK configurado. No se afirma haber probado Android ni los controles Gradle de release.
- Checklist de dispositivo y comandos en `docs/android-setup.md`.
- Persisten tres warnings CSS; el empaquetado local agrega un warning de tamaño inicial (aprox. 829 kB, dentro del límite de error de 1 MB).
- `npm audit`: 60 alertas, incluidas 3 críticas; revisión de dependencias pendiente.
- Sin verificación visual: el navegador de pruebas no pudo acceder al servidor local.
